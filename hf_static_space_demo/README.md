# Electrolaryngeal Speech Recognition Demo

Static public demo for a patient-adapted electrolaryngeal speech recognition
pipeline. It compares cached off-the-shelf Whisper outputs against cached
Whisper + LoRA adapted-model outputs, then plays a cached Ryan/Piper TTS version
of the adapted text.

This Space does not run live inference. That keeps the public demo free,
instant-loading, and safe for resume/recruiting use.
